# 07_GLOSSARY - Naming System & Recurring Names (SINGLE SOURCE)
Version v1.43

## G0 - PRINCIPLE & USAGE
- NARRATIVE LEVEL: translate by SENSE into "Italian (English)" at the FIRST occurrence, then only Italian. Applies to EVERYTHING built from transparent English words: personal names, surnames, epithets/nicknames, places/settlements, ships/vessels, taverns/inns, organizations/groups/companies, signs, titles. (ABILITY / SPELL / MOVE / ACTION NAMES are a SPECIAL CASE -> see G24: FFXIV/FF-iconic names are KEPT, only the effect is in Italian.) If no standard rendering exists, CREATE one. The English in parentheses is a provenance label.
- LORE-FIRST: before coining a NEW rendering for an unlisted name, consider what the place/character/thing IS in the lore, so the adaptation reflects its meaning, not just its words.
- OPERATIONAL LEVEL: in the SAVE and in WIKI queries use the pure ENGLISH canonical name; the Italian rendering lives only in narrative output.
- PRIORITY: if a name is in the FIXED LISTS (G5-G27) use that rendering VERBATIM; for any name NOT listed apply the METHOD (G1-G4). Never improvise a different rendering for a listed name.
- TERMINOLOGY: Primal stays Primal; the WORD "Job"/"Jobs" AND "class/classes" -> "Classe"/"Classi" in output (the mechanic, base OR advanced, NO lexical distinction: "la tua Classe", "cambiare Classe"); individual Class NAMES are rendered per G18 (Italian FF tradition: White Mage -> Mago Bianco), keeping iconic untranslatables (Dragoon, Ninja, Samurai); the aether family is rendered (G6); TEMPERED (learned) = Temprato / ENTHRALLED (common) = Asservito; ability/spell/Action NAMES -> see G24 (FFXIV/FF-iconic names KEPT; only the effect rendered in Italian).

## G1 - ADAPTATION METHOD
5 STEPS:
1. CLASSIFY: transparent English words -> translate; opaque/fantasy/other-language coinage -> keep unchanged. NATURE/PLANT WORDS & MEANINGFUL TRANSPARENT SURNAMES TRANSLATE: a common English word (a plant, animal, colour, element, deed, or physical trait) is TRANSPARENT and gets rendered even when it is used as a SURNAME or a TOPONYM — Hawthorne = biancospino, so Hawthorne Hut -> Capanna Biancospino AND the Hawthorne family -> i Biancospino (Rolfe/Rosa/Amelain Biancospino); Greystone (the noble bastard surname of Coerthas, akin to Snow in GoT) -> Pietragrigia (Haurchefant Pietragrigia); Wyrmblood (the Azure Dragoon lineage/title) -> Sanguedidrago (Estinien Sanguedidrago); Tenfingers -> Diecidita (Baderon Diecidita); Ironheart -> Cuordiferro (the explorer family: Nedrick, Klynthota Cuordiferro); Blackthorn -> Spinanera (Gerolt Spinanera). Do NOT keep such a word in English just because its spelling reads as a family name; classify by its SENSE (G0 binds transparent surnames/epithets). Conversely, CULTURAL & INVENTED SURNAMES REMAIN UNCHANGED: French-style Elezen nobility (de Fortemps, de Borel, Dangoulain, de Haillenarte), ancient-tongue Roegadyn (Bloefhiswyn, Wilfsunwyn), and metric Lalafell names (Nanarito, Adeledji, Modi, Taru) are culturally opaque and kept as-is.
2. DECOMPOSE into elements (Ale-port, White-brim, Storm-blade).
3. TRANSLATE each element by sense and RECOMPOSE into the most natural Italian form, reordering modifier/head per Italian syntax.
4. FUSED COMPOUND is the DEFAULT for SHORT concrete word+word coinages (real-toponym model Portoferraio/Portovenere): Aleport -> Portobirra; Wineport -> Portovino; Stormblade -> Lamatempesta; Lakeland -> Terralago; Quarrymill -> Cavamulino. Keep natural phrasing where the name is inherently phrasal: noun+adjective stays two words (Whitebrim -> Orlo Bianco), and head + proper-name or Front/Gate/Bridge uses a preposition (Whitebrim Front -> Avamposto di Orlo Bianco).
5. EUPHONY + COMPLETENESS GATE: keep the translation only if COMPLETE, sensible and IMMERSIVE. If it would be partial, truncated, hybrid, comic or tonally wrong, leave the ORIGINAL unchanged (written ONCE, no parentheses). NEVER half-translate (e.g. "Camp Drybone" with only Camp->Campo): either fully translate the distinctive element too, or keep the whole name in English once.
   THE DEFAULT IS TO TRANSLATE — THE GATE IS A NARROW EXIT, NOT A PREFERENCE. Anything with a transparent English sense GETS RENDERED: the parenthesised "(English)" at first occurrence is the safety net, so the GM can adjust a rendering at the table, and it makes an imperfect Italian name CHEAP while an untranslated one is a silent loss. So the gate fires ONLY when the sense is genuinely opaque or the Italian would be actively comic — NOT because the name is unfamiliar, NOT because a first attempt came out clumsy (try the other shapes in the flowchart first), and NOT because keeping the English felt safer.
   OBSERVED FAILURE (real run, three names in one beat): "Buscarron's Druthers", "Highbridge" and "Qiqirn Firewater" all left in English. All three are transparent and all three render cleanly — Highbridge -> Ponte Alto (G3 '-bridge -> Ponte di-'); Qiqirn Firewater -> Acquafuoco Qiqirn (step 4 fused compound); Buscarron's Druthers -> Il Capriccio di Buscarron (flowchart 3(a) "X's Y" -> "Y di X"; 'druthers' = one's preference/whim, from "I'd rather" — it is NOT a drinking vessel, and the earlier attempt 'Il Bevitoio di Buscarron' failed by MISREADING THE SENSE, not by being too Italian). DIAGNOSIS WORTH KEEPING: a bad rendering is a translation error to fix, not evidence that the name should stay English. Re-read the sense, then re-apply the method.
   GENUINE GATE CASES (what the exit is actually for): opaque coinages and fantasy/Latin/Japanese proper names (Sastasha, La Noscea, Azys Lla, Thok ast Thok) — these are 'all kept' at flowchart step 2, written once with no parentheses.

LEAN PRINCIPLE (apply throughout - prefer the SHORTEST form that stays clear and immersive):
  L1. Prefer APPOSITION, dropping "di/del", when euphonic: Mar di Nuvole; Riva Sangue; Valle Teschio; Campo Lago di Bronzo.
  L2. DROP a generic geographic head (Gully, Hollow, Stand, Drydocks, Pier...) when the distinctive element stands alone: Raincatcher Gully -> L'Acchiappapioggia.
  L3. Render a long English descriptor with the SINGLE most evocative Italian word: Drydocks -> Carenaggio (not "Bacini di Carenaggio"); Oakwood -> Querceto.
  L4. FUSE only short, concrete word+word coinages: Lakeland -> Terralago; Halfstone -> Mezzapietra.
  L5. Use a PREPOSITION when the modifier is ABSTRACT or a PROPER NOUN: Summerford -> Guado d'Estate; Brayflox's Longstop -> Lungasosta di Brayflox.

DECISION FLOWCHART (for any name NOT in the fixed lists):
  1) CLASSIFY each distinctive word (transparent -> translate / fantasy-Latin-Greek-Japanese-proper -> keep).
  2) If ALL kept -> write ONCE, no parentheses (Italian article/particle only).
  3) If >=1 translatable -> decompose, render via Element Map (G3), RECOMPOSE by SHAPE:
       (a) "X's Y" -> "Y di X"   (b) Head + ProperName / Keep-Castle-Gate-Front-Bridge -> "[Italian head] di [Name]"
       (c) short concrete word+word coinage -> FUSED   (d) noun+adjective -> two words / compressed apposition.
     Then pick the LEANEST euphonic option (apply L1-L5).
  4) EUPHONY/ECONOMY GATE: if partial/clunky/comic -> keep original ONCE.
  5) PARENTHESIS TEST (G2): "(English)" only if the core NAME WORDS changed.

## G2 - PARENTHESIS TEST (kills the "X (X)" bug)
The English in parentheses appears ONLY when the core NAME WORDS differ from the Italian. A changed ARTICLE or particle (The -> Il/Lo/La/L'; of -> di) does NOT count as a translation. So a name whose distinctive words you did NOT translate (fantasy/Latin/other-language) is written just ONCE with NO parentheses - La Noscea, Sastasha, Costa del Sol, Studium, Rostra, Archeion, Labyrinthos (NEVER "Lo Studium (The Studium)" nor "La Noscea (La Noscea)"). There is NO "official localization" exception, and never put the English first (order is always Italian (English)). ARTICLE GRAMMAR WITH KEPT NAMES: a KEPT foreign/proper name takes the normal Italian preposizione articolata, spelled FUSED — della Misery, dei Tentacoli del Kraken, sulla Misery — NEVER the broken split form 'de la Misery' / 'de i Tentacoli'.
GRAMMATICAL GENDER AGREEMENT: article and adjective agree with the GRAMMATICAL GENDER of the rendered ITALIAN noun, NEVER with the referent's SEX nor with the English source. An Italian noun keeps its own gender even when it names a male person: 'sentinella' is feminine -> **la sentinella / le Sentinelle del Bosco / della Sentinella** even for a male guard (never 'il Sentinella' / 'i Sentinelle' / 'del Sentinella'); likewise 'la guardia', 'la recluta', 'la spia', 'la vedetta' stay feminine for men. This also forces the FUSED preposizione articolata: di + la Capanna -> **della Capanna** (never 'di Capanna'). Failure shape: 'il Sentinella', 'i Sentinelle del Bosco', 'del Sentinella', 'Dispensiere di Capanna'.

## G28 - UNITS OF MEASUREMENT (Eorzean, never translated)
Which unit and how to convert: 06 A2. Here, how they are WRITTEN.
- BINDING FORMS: yalm · fulm · ilm · malm · ponze · onze · tonze.
- NEVER TRANSLATED: 'iarda', 'libbra', 'piede', 'oncia', 'miglio' are wrong. Coined setting words, so G3's parenthesis test does not apply.
- LOWERCASE, even after a numeral: '6 yalm', not '6 Yalm'.
- INVARIABLE IN THE PLURAL: tre yalm, sei fulm, dodici ponze, due malm. Never 'yalms', never 'ponzi'.
- BRACKETED CONVERSION, when used: `<numero>m` glued, no words — '7 yalm (10,5m)', '3 malm (4,8km)', '10 ponze (4,5kg)'. Italian decimal comma.
